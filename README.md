## Project Title

**ECG Arrhythmia Classification Using a Multi-Scale 1D Convolutional Neural Network**

## Project Overview

This project investigates ECG heartbeat classification using supervised deep learning. It uses a Multi-Scale 1D Convolutional Neural Network to classify heartbeats into five AAMI categories: N, S, V, F, and Q.

The project examines patient-level evaluation, class imbalance, RR-interval features, and the effect of model components on classification performance.
